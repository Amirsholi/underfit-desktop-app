# Under-Fit 2.1.0 - Notas de version

Version correctiva enfocada en la gestion real de membresias del gimnasio.

## Cambios

- Renovacion mensual: 1 mes / 30 dias.
- Renovacion trimestral: 3 meses / 90 dias.
- Renovacion semestral: 6 meses / 180 dias.
- Botones del modal de renovacion mas anchos para una vista mas equilibrada.
- Labels de configuracion de precios actualizados a 1, 3 y 6 meses.
- Metadata de la app actualizada a `2.1.0`.

## Verificacion
