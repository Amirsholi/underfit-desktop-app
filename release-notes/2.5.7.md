# Under-Fit 2.5.7

- La cédula ahora se puede corregir desde Usuarios → ficha del socio → Guardar cambios.
- Se conservan pagos, ingresos, rutinas, inscripciones, asistencias y ventas pendientes vinculados al socio. No se modifican sus importes ni se crea un usuario nuevo.
- Si la nueva cédula pertenece a otro socio, se rechaza la edición. Si hay un conflicto en sus registros, se revierte toda la operación.
- Disponible tanto en instalaciones con SQLite como con la API PostgreSQL. No requiere una migración de esquema.

Validación: 145 pruebas JavaScript, 29 unitarias .NET y 24 de integración PostgreSQL, incluyendo corrección de CI, duplicados y conservación de historial.

Esta actualización contiene únicamente la corrección de cédulas sobre la versión 2.5.6. La etapa de accesos móviles continúa en desarrollo independiente.
